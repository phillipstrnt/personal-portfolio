## Local preview

Open `index.html` in a browser or run a local server from this folder:

```sh
python -m http.server 8000
```

Then open `http://localhost:8000`.

## Deploy

This is a static site with no build step. Connect the repository to Netlify or Vercel with the repository root as the output directory. The existing `netlify.toml` and `vercel.json` are included for those platforms.
